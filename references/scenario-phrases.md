# 场景话术库

> 用法：沟通前翻一遍，选对应场景，可直接照说或按自己语气改编。
> 心法：**情绪不接招，只谈事；关键安排，书面留痕。**

## 总原则
1. 不接情绪，只谈事：对方指责/嘲讽/质问都是情绪，我只回应"事实 + 安排"
2. 少辩解，多确认：被冤枉时不急着自证，把对方要求复述确认一遍
3. 书面留痕：任务、出差、请假、求助，尽量微信/邮件
4. 用提问把球抛回去：不直接说"不"，让对方排序、定优先级、做决定
5. 软中带硬：语气温和，内容有边界；涉及健康和安全一步不让
6. **真实比讨好更有效**：刻意迎合的效果远不如真实表达；真实本身就是一种被尊重的前提
7. **善良要带锋芒**："好人"形象若没有拒绝的勇气，只会成为别人欺负你的理由

## 话术底层结构（任何场景通用）★先看这里

### 结构一：非暴力沟通四要素（观察-感受-需要-请求）
冲突沟通时，把话说成四段，天然避开"指责-防御"循环：
1. **观察**：说事实，不说评价——"这周三天晚上加班到 10 点"（不是"你总让我加班"）
2. **感受**：说我的状态——"我身体已经比较疲劳"
3. **需要**：说我的诉求——"我需要保证基本的休息"
4. **请求**：给具体可执行的请求——"这次能不能排到下周，或找 XX 分担？"

### 结构二：安全氛围优先（冲突升级时先降温再谈事）
对方情绪上来时，道理是讲不通的——先恢复"安全对话"的氛围，再谈内容：
1. **先共情降温**：「我理解你现在比较着急/不满」——让对方感到被听见
2. **找共同目的**：「我们的目标都是把这事顺利推进」——从"对立"回到"共同"
3. **再谈分歧**：「我的想法是……你看怎么协调？」
- 判断标准：如果对话让你感到"不安全"（被攻击、被否定人格），先暂停：「这个话题我晚点单独跟您聊」——不要在不安全的氛围里硬谈

### 结构三：对比法（澄清误解，不辩解）
被误解时，用"我不是……而是……"句式澄清，比"不是我的错"更有效：
- 「我不是不愿意配合，而是手头 XX 今天必须交，怕耽误两边。您看怎么安排优先级？」
- 「我不是怕事，而是之前对流程不了解，想简单了。组织安排我一定配合。」

### 结构四：拒绝黄金公式（共情 + 理由 + 替代方案）★最常用
被求助/被甩活时，最优雅的拒绝结构：
> 「我特别理解你赶进度的着急（**共情**），但我今天必须完成这份报告，不然影响明天的评审（**理由**）。不过我这有个现成模板，发你参考，或许能省点时间（**替代方案**）。」

要点：
- 共情让对方情绪上不被拒绝；理由让对方知道你的优先级；替代方案让对方有台阶下
- 合理拒绝不是"断绝关系"，而是让对方知道你的工作节奏，避免后续无理请求
- 拒绝之后，对方反而更尊重你（拒绝的勇气=边界清晰=靠谱）

## 场景 A：被当众否定/贬低付出
- 不当场争辩，不卑微道歉；简短接住，引到"接下来怎么安排"
- 「嗯，大家都不容易。那我手上这块收尾怎么安排，您定个优先级？」
- 心里话：TA 说的是 TA 的感受，不是事实；在场的人心里有数

## 场景 B：被质问（"你怎么一脸懵"）
- 承认状态，落到具体事，把"懵"翻译成"任务多、缺排序"
- 「任务一下比较多，我需要捋一下。您看这几项里哪个最急，我先做哪个？」

## 场景 C：被吐槽能力（"能干的是往死里干"）
- 不辩解能力，谈状态、谈安排、谈明天
- 「我不是不想干，今天状态确实到极限了。明天一早我第一件事就做这个，您看行吗？」
- 底线：对方继续阴阳就沉默——沉默也是一种回应，比辩解体面

## 场景 D：被临时甩活（用黄金公式 + 优先级确认）
- 不硬接不硬拒，展示全貌，逼对方排序
- 「我现在手上有 A、B、C。您新加的这个 D，您看插在哪项前面？A 是 XX 在等，B 的节点是 X 号……」
- 对方仍要求全做：「好的，那我按 A→B→C→D 做，D 可能要 X 号才能交，您看可以吗？」（提前说清延期预期）
- 同事求助版：「我理解你这块急（共情），但我手头 XX 今天必须交（理由），要不你先找 X 帮忙/我晚点帮你看看（替代方案）？」

## 场景 E：申请休息/请假/回程安排
- 提前 2-3 天 + 事实陈述 + 书面（微信文字），不口头申请
- 「XX 这边我安排到 X 号。X 号到 X 号我想请两天假休息一下，手上剩余事项已列好交接清单，您看可以吗？」
- 被拒不纠缠，但记下这一次

## 场景 F：需要支持/资源
- 提前书面发清单 + 时间点
- 「材料清单我列好了（附清单），需要 X 个。您看是您这边协调，还是我自己解决？」
- 关键：书面 + 提前，对方再甩"你早干嘛去了"，你手里有记录

## 场景 G：对方情绪爆发/说狠话
- 不接情绪，平静复述事实，让对方知道你在记录
- 「我听到您的要求是 X，我记一下，X 时间前完成，对吧？」
- 效果：情绪型的人看到对方在"记录"，通常会自动收敛
- 若对话环境不安全（被当众羞辱）→ 「这个话题我回头单独跟您说」，先离开不安全的场合

## 场景 H：被要求"帮别人"（自己任务已完成/已到极限）
- 「我的活 X 点前交给您。帮 XX 的话，您看怎么安排我的优先级？」
- 让对方做取舍，而不是默默承担所有

## 场景 I：被人在领导面前当众"带节奏"★重点
- 教训：现场解释越描越黑；涉密/体制语境里，"我怕 X"本身就是负面信息
- 原则：**不辩解"怕"，只表态"配合"**
- 被点：「组织需要，我肯定配合的。这事儿我记下了，回头我主动跟您汇报。」
- 被追问"当初为什么推"：「之前考虑不周，怕耽误进度，想简单了。组织安排我一定配合。」（对比法：不是怕事，而是考虑不周）
- 事后补救：主动正面回应，把"拒绝"翻译成"服从组织"；之后在领导面前抢答"配合"

## 场景 J：涉密/敏感话题（升密、审查等）
- 关键认知：拒绝敏感安排 = 被贴"有顾虑/不服从"标签，代价远大于收益
- 打法：**不主动推进，但态度绝对服从**——组织提了就一句「组织安排我就上，我没意见」，绝不解释"为什么不想"
- 被动服从不减分，主动拒绝才减分

## 场景 K：少加班少出差（低调保底）
- **绝不说"我不想加班/出差"**——等于自贴"态度有问题"
- 核心：用事实与策略减负，不用态度减负
  1. 优先级确认法（对付临时加活）
  2. 提前量 + 书面 + 正当理由（健康/家庭，用真实存在的，频率一年几次为限）
  3. 效率控制：活干得"合格但不过度"，避免成为"急活第一人选"
  4. 人设经营：非正式场合偶尔流露"身体一般/家里事多"，让领导潜意识不把你列入"随时可出差"名单
  5. 不揽活、不抢话：积极=好用=活多

## 场景 L：想挡"私活"不想拒"正式活"（控分而非断联）
- 核心心法：**不喜欢一段关系，降低密度就够了，不必撕破脸——把关系"控分"到最低必要密度，是成本最低的疏远方式**
- 错误做法：只拒绝某人、接受别人 → 被看穿 = 公开针对 TA = "闹矛盾/不服从"
- 正确拆解：**只接正式分工的活（职责必须接），挡住私下临时加码的活**
  - 正式分工 → 必须接，用优先级确认控制节奏
  - 私下临时叫 → 「我现在手头在做 XX，这个新活您看排在哪？XX 节点是 X 号，怕耽误」
  - 对方施压 → 「我不是不干，是怕两边都耽误。要不我跟负责人确认下优先级？」（把决定权上交）
- 温差管理：对别人的临时加活用同一套话术，不留"专门不配合 TA"的把柄
- 红线：正式分工不能拒；活可以慢、稳、不返工，但绝不能错
- 长期姿态：**只维持工作必需的交接，不过度输出、不过细相处、不主动汇报私事**

## 场景 M：对方倒打一耙/当众诋毁时
- 错误做法：当众反咬、宣布"以后不干 TA 的活" → 自贴"闹矛盾/不服从"标签，正中对方下怀
- 正确应对：
  - 私下阴阳 → 平静回一句客观事实：「当时是骨折/XX 情况，报告都发你了，确实去不了。」不吵架
  - 人前/领导面前带节奏 → 不当众对线；事后单独找领导客观陈述（不是告状）
  - 继续越界影响权益 → 书面留痕，必要时把证据（报告/记录）给领导看——铁证关键时刻才登场
- 记住：**"不干 TA 的活"永远不说出口，用行动做出来**（场景 L 的方式）

## 场景 N：被孤立/被冷落（边缘化）
- 识别：被排除在信息外、会议不叫、活被绕过——可能是有意孤立，也可能是组织自然调整
- 错误做法：讨好式贴上去、质问"为什么不叫我"、赌气消失
- 正确做法：
  1. **保持职业化输出**：自己的活照干好，该汇报汇报，不缺席不消失
  2. **保持存在感**：例会主动说进展、工作群里正常发言，让人没法"忘掉你"
  3. **不追问不抱怨**：追问"为什么不带我"显得姿态低；让成果替你说话
  4. **观察动机**：若是有意孤立且影响利益 → 按策略路线（保底/脱离）处理；若是自然调整 → 顺势减负

## 场景 O：被抢功/成果被占
- 识别：自己的活被别人拿去汇报、署名被吞、功劳被模糊
- 错误做法：当众拆台"这是我的活"、私下抱怨传播
- 正确做法：
  1. **让成果在正常渠道可见**：自己的工作周报/月报/汇报里写清楚「我负责 XX 部分，已完成 XX」，让领导在正常渠道看到
  2. **关键节点留痕**：重要产出提交时，邮件/微信里明确「XX 部分由我完成，已交付」，cc 相关人
  3. **不主动抢功**：别人汇报时不当场反驳；下次汇报自己多讲细节，让"谁干的"自然显现
  4. **涉及原则**（评优/晋升被冒领）→ 单独找领导，用事实和记录说话，不攻击对方，只陈述"这项工作是我做的"

## 场景 P：被 PUA / 煤气灯效应（打压式否定）★心理防护
- 识别套路：
  1. 频繁贬低你的能力/价值，且不给具体改进点（"你就是不行"）
  2. 否认说过的话/做过的事，让你怀疑自己记忆（"我什么时候说过"）
  3. 把 TA 的情绪/失误归咎于你（"都怪你没提醒"）
  4. 孤立你与外界信息，让你只依赖 TA 的评价
- 关键认知：**领导的表扬就是幼儿园小红花**——今天压迫你让你自我怀疑，明天对你好一点给你情绪补给，都是管理术；不接这个情绪补给，就不会被 TA 拿捏
- 应对：
  1. **只认事实，不认评价**：记录 TA 的原话和情境，用记录对抗"煤气灯"（我记着呢）
  2. **不解释、不证明**：被贬低时不急着证明自己，平静说「好的，我知道了」或直接谈工作
  3. **找旁证**：和信得过的同事/朋友核对"TA 说的对不对"，打破信息垄断
  4. **警惕信号**：频繁自我怀疑、越来越没自信、害怕 TA 的评价 = 该拉开距离，按策略路线处理
- 话术：「您说的我记下了。具体是哪一块需要改进，您给个方向，我去看。」——把模糊否定变成具体问题，TA 答不上来就说明是纯打压

## 场景 Q：跨部门/平级甩锅
- 识别：别的部门/平级把责任推给你，"这不是我们的问题，是你那块的"
- 应对：不接锅、不吵架、用"事实 + 边界"回应
  - 「这个需求当时是 XX 提的，时间点是 X 号（附记录），我们这边按节点做了。您看是哪块信息没对齐，要不要一起确认下？」
- 关键：让责任界定回到"事实和记录"，不进入"你错我错"的争吵

## 场景 R：领导当众批评（合理的）
- 识别：确实是自己有失误，领导当众指出
- 应对：不辩解、不沮丧、简短认领 + 给补救方案
  - 「这个确实是我没做到位，我 X 点前补上/出个方案，您看行吗？」
- 关键：当众批评已经发生，重要的是"接下来怎么办"，姿态对了反而加分

## 场景 S：领导忽冷忽热 / 情绪操控（进阶识别）
- 识别：表扬→打压→表扬循环，让你患得患失、拼命表现
- 本质：这是"搞下级心态的管理术"——用情绪起伏控制你，不花钱就能把你收拾得服服帖帖
- 应对：
  1. **不接情绪补给**：表扬时不飘飘然，打压时不自我怀疑——保持恒定输出
  2. **领导不回消息，不往心里去**：可能只是忘了或不方便回；该怎样还怎样，反而让人觉得跟你打交道轻松（不内耗=竞争力）
  3. **只对"事"负责，不对"情绪"负责**：TA 情绪不好是 TA 的事，我的交付质量是我的事
- 心态：把领导当"客户"而不是"裁判"——服务客户的规则，但客户的情绪不等于我的价值

## 万能收尾句
- 「听组织安排，我没意见。」（涉密/敏感场景）
- 「我记一下，X 时间前交 X，对吧？」（确认任务=留痕）
- 「您定优先级，我按顺序来。」（把球抛回去）
- 「好的，我知道了。」（被贬低时最省力的接法——不辩解不接招）
- 「我理解你急（共情），但我这边 XX（理由），要不这样……（替代方案）」（拒绝黄金公式）
- 「我不是……而是……」（对比法澄清）
