# 提问清单（先问什么，再问什么）

> 用途：处理职场问题时，按阶段向用户提问，把"盲给建议"变成"基于事实的建议"。
> 原则：一次 3-4 问，先问决定方向的，再问细化落地的；能自己查档案得出的不问；问完立即回写档案。
> **注意提问时机**：不要一上来就连环问。流程是——**先建档案骨架（Step 3，不问用户）→ 在合适的时机（用户讲完事件/做完定性后）询问是否补充档案信息 → 用户同意后再按下面阶段提问**。

## 阶段 0：开场摸底（用户第一次讲一件事时）

用户可能只描述了感受（"她总针对我""我好难受"），先还原事实：

1. **具体事件**：最近一次发生是什么时候？TA 具体说了/做了什么？（要原话，不要转述情绪）
2. **在场/知情者**：当时还有谁在场？有没有人知道这件事？
3. **书面凭证**：有没有微信/邮件/记录可以佐证？
4. **频率与起点**：是第一次还是反复出现？大概从什么时候开始的？

> 目的：先把"情绪"换成"事实"，才能判断是不是用户的问题（Step 1 的输入）。

## 阶段 1：定性所需（判断是不是我的问题）

1. **TA 对别人如何**：其他同事怎么看 TA？TA 只对你这这样，还是对谁都这样？
2. **同类事件频率**：近半年类似的事发生过几次？
3. **对方的指责有无依据**：TA 说的"问题"有没有具体事实？还是纯情绪？
4. **你自己的判断**：你觉得自己在这件事里，有没有哪部分确实是自己的疏忽？（诚实自查）

## 阶段 2：权力结构所需（决定策略强度）

1. **考核权**：TA 对你的考核/评优/晋升有决定权吗？
2. **领导知情度**：你们的直接领导/负责人知道这件事吗？什么态度（不管/支持TA/理解你）？
3. **关系期限**：这段关系有期限吗？（师徒几年？项目何时结束？）
4. **可改变的通道**：你有没有可能换组/借调/调岗？所里有先例吗？
5. **TA 的角色**：TA 在组织里是什么位置？你对 TA 需要依赖多少？

## 阶段 3：目标定位所需（决定策略路线）

1. **你的目标**：你最希望这件事最后变成什么样？
   - 选项：让 TA 别这么压 / 换师傅换组 / 调岗或走内部通道 / 考虑离开
2. **你的职业定位**：你是想往上发展，还是保底+省时间？（目标不同，策略完全相反）
3. **你愿意主动到什么程度**：愿意为改变现状主动谈一次吗？还是希望不声张地解决？

## 阶段 4：落地执行所需（细化方案前）

1. **时机**：关键节点（结项/分配/考核）大概什么时候？急不急？
2. **人脉/盟友**：有没有能帮你说上话的人？
3. **可用资源**：手头有哪些筹码（成果、数据、记录、关系）？
4. **风险承受**：如果这次谈不成/冲突升级，你能接受的最坏结果是什么？

## 档案补充时机（对应 Step 3：分两种，区别对待）

**A. 事件内容 → 直接写，不问**
用户讲的事件、原话、在场人、书面凭证，直接回写档案，不问"要不要记"。事件是档案的"肉"，讲了就该记。

**B. 结构化信息缺口 → 主动问，补全关键字段**
用户讲了几件事，但档案里这些**决定策略走向的关键字段**还缺失时，主动询问补全：

| 缺失字段 | 影响 | 参考话术 |
| --- | --- | --- |
| 与 TA 的关系性质（领导/师傅/平级？有无期限？） | 决定话术强度与分寸 | 「TA 是你的直属领导还是平级？这段关系有期限吗？」 |
| TA 对我有无考核权/评价权 | 无考核权→不必怕 TA | 「TA 对你的考核/评优/晋升有决定权吗？」 |
| 领导/负责人是否知情、什么态度 | 知情不管→靠策略自救 | 「你们领导知道这件事吗？什么态度？」 |
| 我的目标/职业定位 | 决定策略路线（发展/保底/脱离） | 「你最希望这件事最后变成什么样？」 |
| 有无换组/借调/调岗通道 | 决定长期策略 | 「你有没有可能换组/借调？所里有先例吗？」 |

**提问时机**：用户讲完 2-3 件事后、或做完定性后、或准备给策略前——确保给建议前关键字段已补全。一次问 3-4 个。
**用户答不上来/不想说**：不追问，按已有信息给出带前提的建议（"如果 TA 有考核权……如果没有……"）。

## 特殊情况：必须追问的触发词

用户说到以下关键词时，先追问再给方案：
- 「他总是针对我 / 欺负我 / PUA我」→ 还原具体事件（阶段 0）
- 「我不想干了 / 我想撕破脸 / 我要反击」→ 先确认目标与风险承受（阶段 3/4），再评估该不该做
- 「领导知道但不管 / 上面不管」→ 确认是否真的知情（阶段 2）
- 「我是不是想多了 / 是不是我的问题」→ 先做 Step 1 定性（阶段 1）
- 「帮我写个话术 / 拟条微信」→ 先确认场景、对象、时间、书面凭证（阶段 0 + 场景匹配）

## 提问后的动作

1. **回写档案**：用户的每个回答，更新到对应档案（对方档案/我的档案/沟通手册）
2. **总结确认**：把理解到的关键事实复述一遍，让用户确认没理解偏
3. **给方案时引用事实**：「基于你说的 X（考核权/期限/目标），建议……」，让用户知道方案是有根据的
