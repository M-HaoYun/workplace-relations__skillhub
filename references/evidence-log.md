# 事件记录与留痕机制

> 用途：把每次冲突变成可追溯的记录。现在用不上，将来用得上——这是保护自己的底气。
> 心力视角：**心力 > 脑力 > 体力**——记录不是为了记恨，是为了"放下"：写下来，就不必反复在脑子里回放；记录归档，情绪就搬出了你的心，存进了文件里。这也是课题分离的落地：把 TA 的行为归档，就不再背着它过夜。

## 一、事件记录模板（每发生一件填一份）

```
【事件记录 No.____】
日期：____
场景：____（出差/单位/线上…）
TA 说了/做了什么：____（附原话，不加修饰）
我当时怎么做的：____
如果重来，我会怎么说：____
在场人 / 可知情者：____
是否有书面凭证（微信/邮件/文件）：____
对我的影响（身体/情绪/工作）：____
```

**记录原则**：
- 只记事实，不写情绪（"TA 很过分"→"TA 说：____"）
- 尽量记原话，原话是证据，转述是主观
- 当天记，别拖——记忆会美化/扭曲

## 二、书面留痕铁律

**重要安排一律文字确认，不裸奔：**

1. **任务确认**：对方口头布置 → 回一条文字总结
   - 「按今天说的，我 X 号前交 X，对吧？有出入您再纠正我。」
2. **出差/请假**：提前 2-3 天微信文字申请，写明时间、事由、交接安排
3. **求助/要资源**：书面列清单 + 时间点，防"你早干嘛去了"甩锅
4. **拒绝/减负**：把"我不干"翻译成"优先级问题"，用文字发出去
5. **重要产出**：交付时写清「XX 部分由我完成，已交付」，让"谁干的"有据可查

留痕的目的：不是对抗，是保护——让"谁安排的、什么时候、要求什么"有据可查。

## 三、证据（铁证）使用原则

### 什么算铁证
- 医院诊断报告、检查单（身体受损时）
- 聊天记录原话（尤其对方催活、贬低、甩锅、承诺的原话）
- 邮件、任务单、书面通知
- 请假/审批流程记录
- 工作成果的署名/提交记录

### 使用原则（重要）
1. **藏而不用**：证据平时安静躺着，不主动出示、不当众亮出
2. **关键时刻登场**：只有影响权益时才出示——被倒打一耙且影响考核/岗位/声誉时，给领导看
3. **绝不当众吵架用**：当众亮牌 = 提前暴露底牌，对方会有准备地歪曲；藏着，对方就不敢过分
4. **一图胜千言**：出示时给"事实摘要 + 证据原样"，不解释情绪、不展开抱怨
   - 例：「X 月 X 日我骨折（诊断报告见附件），已按流程请假（记录见附件），期间 TA 仍要求我远程干活（聊天记录见附件）。」
5. **给谁看有讲究**：直属领导不行时给上级/HR；先给事实，再谈诉求

## 四、记录保存建议

- 聊天记录：重要对话截图存档（存网盘/相册，带时间戳）
- 文档：诊断报告、请假单、任务单归档到安全位置
- 日记式记录：每件冲突按模板记一笔（见上），形成时间线
- 备份原则：重要证据至少两份存储（本地 + 云/照片）
- 时间线思维：多件事件连起来看，单件可能被"解释"，时间线说明"是系统性的"（回到 SKILL.md Step 1 的定性）

## 五、留痕的"副作用"（反制价值）

留痕不只是防御——它本身会改变对方的行为：
- 对方知道你会记录 → 说话会更谨慎，过分的命令会收敛（场景 G 的原理）
- 你养成确认习惯 → 对方想甩锅时发现"有记录"，自然甩不动
- 书面化的请求 → 对方拒绝时也要"书面拒"，TA 要承担拒绝的痕迹

## 六、什么时候"该亮牌"

判断标准（满足 2 条以上考虑出示证据）：
1. 影响考核/评优/岗位/收入等实际利益
2. 对方公开歪曲事实，且不澄清会持续受损
3. 正常沟通已无法停止对方的越界行为
4. 涉及健康/安全/合规的红线问题
