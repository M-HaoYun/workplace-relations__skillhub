# 四档案体系搭建指南

> 用途：把"模糊的难受"变成"可管理的记录"。档案是策略的依据、情绪的出口、未来的底气。
> 原则：只记录事实，不评价动机、不用于传播、不成为仇恨清单。
> 方法论底色：**生态位思维**（记录的不只是"TA 做了什么"，更是"我在这个环境里站在哪个生态位、值不值得纠缠"）、**课题分离**（只对我的课题负责，不背 TA 的课题）。

### 行为模式画像（归类记录，附原话）
1. **否定式管理（情绪打压）** — 例：「比你累的人多的是」（质疑能力/态度/付出，常在人多的场合）
2. **单边加码（甩活）** — 不考虑在途任务/身体状态，临时大量布置
3. **资源不给、问题甩锅** — 例：「你早干嘛去了」（而正是 TA 的安排）
4. **边界侵犯（时间/身体）** — 通宵、站票、连续出差、临时通知
5. **自我优先** — 自己的行程优先，把重活压给下属
6. **在领导面前投射负面标签** — 当众定性"不配合/怕事/心理有问题"
7. **抢功/模糊功劳** — 你的成果被 TA 拿去汇报
8. **孤立/信息封锁** — 重要信息绕过你，让你失去判断依据
9. **煤气灯（PUA）** — 否认说过的话、让你怀疑自己记忆/能力
10. **情绪操控** — 表扬→打压→表扬循环，让你患得患失（"幼儿园小红花"式管理）

### 应对原则速查
1. 不内化 TA 的评价（课题分离：TA 的评价是 TA 的课题）
2. 情绪不接招，只谈事
3. 关键安排书面化
4. 记录留痕
5. 健康是底线
6. 只认事实，不认评价（防煤气灯）
7. 控分而非断联（不喜欢就降密度，不撕破脸）

## 档案二：我的档案.md（记录"我"）

- **基本信息**：年限、单位、岗位、涉密身份等
- **我真实付出过什么**：按时间记录（出差、加班、扛过的活）——这些不是"应该的"，是实打实的付出
- **我的优势**：执行、情绪稳定、能吃苦但仍有判断……
- **我的底线（划死）**：健康/合理性/尊重/留痕
- **我的目标（重要）**：求发展 / 保底省时间 / 脱离某人 / 离开环境——目标决定策略路线
- **我的生态位**：我的能力在现阶段的组织里能带来什么？有没有更被需要的地方？（有时候不是我不够优秀，而是这个环境不需要这类人才）
- **我的课题清单**：哪些是我的课题（交付质量、边界、健康、成长），哪些不是（TA 的情绪、TA 的管理、TA 的评价）——写下来，划清界限
- **自我提醒**（心寒、自我怀疑时逐条读）：
  - TA 否定的是我的"表现"，不等于我的"价值"
  - 同事普遍吐槽 TA → 不是我的问题
  - 我照做是出于性格和职业素养，不等于我应该被这样对待
  - 我会感到心寒，说明我尊重自己的付出——这是健康的信号
  - 我只需要对"事实"负责，不需要对"TA 的情绪"负责
  - 记录里的每一笔，都是我未来的底气
  - 凡事发生皆有利于我——这次吃的亏，是下次的记性
  - 我不需要被所有人喜欢，我只需要守住自己的课题

## 档案三：沟通手册.md（记录"怎么应对"）

- **沟通总原则**：情绪不接招/少辩解多确认/书面留痕/把球抛回去/软中带硬/真实比讨好更有效/善良带锋芒
- **话术底层结构**：非暴力沟通四要素（观察-感受-需要-请求）、安全氛围优先、对比法、拒绝黄金公式（共情+理由+替代方案）
- **场景话术库**：见 `scenario-phrases.md`（按场景挑选，A-S + 万能句）
- **向上与组织策略**：正常渠道汇报、不告状、留痕、身体第一
- **事件记录模板**：每发生一件填一份
- **应急卡片**：把最常用的 3 句话术写在最前面（如：优先级确认、听组织安排、我记一下X号前交、拒绝黄金公式）

## 档案四：领导档案.md（记录"关键决策人"）

| 项目 | 内容 |
| --- | --- |
| 称呼 |  |
| 角色 | 决定什么（升职加薪/考核/分配） |
| 接触频率 | 常接触/偶尔/几乎没有 |
| 他的生态位 | 他要对谁负责、他需要什么产出、他的压力来源 |

- **已知关键事实**：知情与否、对矛盾的立场、公开场合反应
- **关注点**（推测）：服从组织安排、人能扛事、不搞麻烦
- **经营策略**（按我的目标）：
  - 求发展 → 成果可见度、正常汇报、关键时刻表态、找托举和盟友、适度求助建立关系
  - 保底 → 不树敌、不突出、不添麻烦，维持"省心靠谱"印象；把他当客户不当裁判
- **红线**：不抱怨告状、不表现出怕事躲事、不传闲话

## 使用约定

- 新事件 → 追加到人物档案事件记录表
- 新场景 → 补充到沟通手册
- 每次沟通前，先翻沟通手册选话术
- 情绪低谷 → 读"我的档案"自我提醒
- 每季度回顾一次：档案是否反映最新情况，策略是否需要调整，我的生态位是否变化
